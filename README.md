# 📰 News Stream

A responsive news aggregation web application built using HTML, CSS, and Vanilla JavaScript.

News Stream fetches real-time news from the GNews API and allows users to browse articles across different categories, search for news, and open original articles.

##  Features

-  Fetches real-time news using the GNews API
-  Client-side search functionality
-  Category-based news browsing
-  Dynamic rendering of news articles
-  Category-based caching to reduce unnecessary API requests
-  Loading state while fetching news
-  API and network error handling
-  Empty state for unavailable or unmatched articles
-  Responsive design
-  Uses `sessionStorage` to preserve the selected category and search query
-  Opens the original news article in a new tab

---

##  Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- REST API
- Fetch API
- GNews API
- sessionStorage
